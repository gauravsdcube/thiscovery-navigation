# Changelog

All notable changes to this module are documented in this file.

## 1.0.1 (September 1, 2026)

- Enh: Per-item Show icon control so the top bar can use labels only
- Fix: Second- and third-level menu labels align to the left instead of sitting indented to the right
- Fix: A top-level item is no longer repeated as the first entry in its own submenu
- Fix: Nested items use the same top-bar type settings (weight, size, transform) instead of a hardcoded bold

## 1.0.0 (September 1, 2026)

- Enh: Site top bar managed as a three-level menu tree (groups, pages, forms, maps, custom URLs)
- Enh: Administration drag-and-drop tree with unused-item tray and per-item edit
- Enh: Nested desktop dropdowns and hamburger / floating-bar accordion for nested items
- Enh: Per top-level item mobile placement (hamburger, floating bar, or hidden)
- Enh: One-shot migration of theme hamburger / floating item lists and custom hamburger links
- Enh: Collapsible admin sections with Expand all / Collapse all and ? guidance
